# Project 04: Networking Fundamentals

## Overview

This project focused on developing practical networking fundamentals using Kali Linux.

The goal was to understand how a system communicates across local and external networks and how networking concepts such as IP addressing, subnetting, routing, MAC addresses, ARP, DHCP, DNS, TCP, UDP, ports, and sockets work together.

The project also introduced a structured troubleshooting methodology and demonstrated how network activity can be correlated with local processes during a security investigation.

## Objectives

- Identify network interfaces and IP addresses
- Understand IPv4 addressing and CIDR notation
- Understand network and host portions of an address
- Understand basic subnet masks
- Identify the local network and default gateway
- Understand private and public IPv4 addressing
- Understand the purpose of NAT
- Inspect MAC addresses and neighbor information
- Understand the purpose of ARP
- Understand DHCP and automatic network configuration
- Understand DNS name resolution
- Compare TCP and UDP
- Understand ports and sockets
- Recognize common network services and ports
- Inspect active TCP connections
- Correlate network connections with running processes
- Understand basic TCP connection states
- Trace network paths between systems
- Understand the OSI and TCP/IP models
- Build a structured network troubleshooting workflow
- Apply networking concepts to SOC-style investigation
